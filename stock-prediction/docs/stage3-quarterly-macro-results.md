# 단계3 결과 — 분기 펀더멘털(항목2) + 거시 레짐(항목3)

50종목(한국 24 + 미국 26), 롱숏(시장중립)으로 세 피처셋을 **동일 샘플(교집합)**에서 비교.
실행: `sp-stage3`

| 피처셋 | 내용 |
|---|---|
| B_ann | 가격 + 펀더멘털(연간, 연 1회 갱신) |
| B_q | 가격 + 펀더멘털(분기 TTM 결합, 분기 갱신) ← **항목2** |
| B_qm | 가격 + 펀더멘털(분기) + 거시 레짐 ← **항목3** |

펀더멘털 스냅샷: 연간 176 → 분기결합 277개(갱신빈도 ↑). 공통 샘플 45종목
(금융주 5곳은 매출/영업이익 계정 부재로 제외).

## 항목2 — 분기 펀더멘털: LightGBM에서 명확한 개선

- **h=20 LightGBM: RankIC -0.012 → 0.029, 롱숏 샤프 -0.04 → 0.92.** 분기 갱신으로
  PIT 재무가 4배 자주 새로고침되며 트리 모델의 신호가 살아났다.
- **h=60 LightGBM: RankIC 0.127 → 0.161** (추가 개선). 단 h60은 리밸 5회로 샤프는 noisy.
- Ridge는 개선 없음(혼조). 선형 모델은 추가된 시간 해상도를 활용하지 못함 — 비선형
  상호작용을 쓰는 트리에 특히 유효하다는 해석.

## 항목3 — 거시 레짐: 집계 효과는 작지만 '국면 의존성'을 드러냄 ★

- 집계 RankIC 기여는 미미(B_qm ≈ B_q), 샤프만 소폭(h20 0.92→1.05).
- **핵심은 레짐 분할.** B_qm LightGBM 롱숏을 VIX 중앙값(17.3)으로 나누면:

| 국면 | 리밸 | 평균수익/회 | 샤프 |
|---|---:|---:|---:|
| 저VIX(평온) | 9 | **+10.40%** | **2.77** |
| 고VIX(스트레스) | 10 | -1.73% | -0.55 |

  → 이 펀더멘털 롱숏은 **평온장에서 강하고(샤프 2.77) 스트레스장에서 무너진다(-0.55).**
  거시지표 자체가 알파를 주기보다, **언제 전략이 통하는지(국면)를 알려준다.**

## 종합 해석 (정직)

- **항목2는 성공**: 분기 펀더멘털이 LightGBM 신호를 분명히 개선(RankIC·샤프).
- **항목3은 "조건부 성공"**: 거시를 피처로 넣는 것만으로는 미미하나, **레짐 필터로
  쓰면 실질적**이다 — 저VIX에서만 베팅하면 샤프 2.77.
- 그간의 여정: (1) 가격만=신호없음 → (2) 펀더멘털=중장기 신호 → (3) 롱숏=베타아닌 알파
  → (4) **분기화로 신호 강화 + 거시로 국면 식별**. 신호의 크기·조건이 점점 또렷해졌다.

# 단계1 베이스라인 결과

가격/기술적 피처만으로 횡단면 수익률을 예측하고, 상위 K종목 롱 전략을
워크포워드로 백테스트해 **기준선 성능**을 측정했다.

실행: `sp-baseline` (또는 `python -m stock_prediction.baseline`)

## 실험 설정

| 항목 | 값 |
|---|---|
| 유니버스 | KOSPI 대형주 24종목 |
| 기간 | 2024-06-25 ~ 2026-06-25 (거래일 460일) |
| 피처 | ret_1d, ma_ratio, mom_20, vol_20, rsi_14, volume_z (날짜별 횡단면 zscore) |
| 타깃 | 미래 5영업일 수익률 |
| 검증 | 워크포워드 train=126 / embargo=5 / test=21 / step=21 (폴드 15개) |
| 백테스트 | 상위 5종목 동일가중 롱, 5일마다 논오버랩 리밸런싱, 왕복비용 25bp |

## 결과

| 모델 | IC | RankIC | 방향적중 | 전략수익 | 샤프 | MDD |
|---|---:|---:|---:|---:|---:|---:|
| Momentum | 0.049 | 0.020 | 48.1% | 211.1% | 2.18 | -20.5% |
| Ridge | 0.044 | -0.001 | 53.8% | 208.2% | 2.36 | -16.9% |
| LightGBM | 0.003 | -0.018 | 51.0% | 210.0% | 2.56 | -15.6% |
| **벤치마크(동일가중)** | | | | **197.4%** | **3.25** | **-15.1%** |

## 해석 (정직한 평가)

- **예측 신호가 사실상 없다.** IC·RankIC가 0 부근(LightGBM RankIC는 음수).
  가격/기술적 피처만으로는 횡단면 5일 수익률에 유의미한 예측력이 없다.
- **전략이 벤치마크를 위험조정 기준으로 이기지 못한다.** 전략 누적수익(≈210%)이
  벤치마크(197%)보다 약간 높아 보이지만, 이는 해당 기간 대형주 동반 강세(벤치마크
  자체가 +197%) 때문이다. **샤프는 벤치마크(3.25)가 모든 전략(2.18~2.56)보다 높다** —
  상위 5종목 집중이 알파 없이 변동성만 키웠다.
- 즉, 단계1은 "가격만으로는 부족하다"는 **기준선을 확립**했다. 이게 정상적이고
  중요한 결과 — 이후 단계가 넘어야 할 막대다.

## 한계 (결과 과신 금지)

- 표본이 작다: 24종목 × 2년. 통계적 유의성 낮음. 폴드 15개.
- 단일 강세장 구간만 포함 — 하락장/횡보장 일반화 불가.
- 수정주가 미적용(MCP 시세에 Adj Close 없음 → close 사용). 배당 영향 미반영.
- 거래비용·슬리피지 단순화(고정 25bp), 시장충격·체결지연 미반영.
- 생존편향: 현재 상장 대형주만 — 상폐 종목 미포함.

# 타깃 기간 스윕 결과 — 펀더멘털은 중장기에 유효 (첫 신호 확인)

예측 기간(horizon)을 **5 / 20 / 60일**로 바꿔가며, 가격(A) vs 가격+펀더멘털(B)을
동일 샘플로 비교했다. 50종목(한국 24 + 미국 26), 새 데이터 없이 타깃만 변경.

실행: `sp-horizon` (또는 `python -m stock_prediction.horizon_sweep`)

## 해석 (정직한 평가)

- **가설 확인 — 예측 신호 측면.** 펀더멘털의 RankIC 기여(B−A)가 horizon과 함께
  **단조 증가**한다: LightGBM 기준 +0.006(5일) → +0.023(20일) → **+0.140(60일)**.
  60일에서는 절대 RankIC도 **0.127**로, 그간 ≈0이던 신호가 처음으로 실질 수준에 도달.
  → "펀더멘털·가치 팩터는 단기가 아니라 중장기 수익률을 설명한다"는 통설과 일치.
- **단, 아직 벤치마크 샤프를 못 넘는다.** 예측력(RankIC)은 분명히 좋아졌지만, 상위 5종목
  롱 전략의 샤프는 동일가중 벤치마크(특히 강세장 h60=3.87)에 못 미친다. ΔSharpe도
  대체로 음수. 즉 **병목이 '신호 부재'에서 '포트폴리오 구성·시장베타'로 이동**했다.
- h60은 리밸런싱 횟수가 ~8회로 적어 샤프 추정이 noisy 한 점도 감안해야 한다.

## 결론 / 다음 액션

이번 단계의 핵심 수확: **신호는 존재하며, 적절한 기간(중장기)에서 드러난다.**
이제 우선순위는 "더 많은 신호"보다 **신호를 수익으로 바꾸는 구성**이다.

1. **롱-숏(시장중립)** 포트폴리오: 상위 K 매수 + 하위 K 매도 → 시장베타 제거.
   강세장 벤치마크가 아니라 0 대비로 평가되어 RankIC가 수익으로 직결된다. (최우선)
2. **중장기 타깃(20·60일)을 기본값으로** 채택해 펀더멘털 신호를 살린다.
3. **분기 펀더멘털 + 장기 이력**으로 표본·갱신빈도 확대(다음 데이터 작업).
4. 리밸런싱 표본을 늘리기 위한 더 긴 가격 이력.

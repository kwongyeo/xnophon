# 최종 구성 ablation — 개선들의 누적 기여 (capstone)

연구 여정에서 얻은 세 개선(분기 펀더멘털 · 시장중립 · 레짐 필터)을 누적 적용하며
롱숏 성과 변화를 측정. h=20, LightGBM, 동일 공통 샘플(45종목·567거래일).

실행: `sp-final`

## 결과 사다리

| 구성 | 활성% | 전략수익 | 샤프 | MDD |
|---|---:|---:|---:|---:|
| C0 원조(풀링 + 연간) | 100% | -11.7% | **-0.04** | -40.3% |
| C1 + 분기 펀더멘털 | 100% | 57.4% | 0.92 | -33.4% |
| C2 + 시장중립 | 100% | 63.3% | 1.23 | -11.1% |
| C3 + 레짐필터(최종) | 47% | 71.9% | **1.57** | **-2.7%** |

## 해석

각 단계가 **샤프를 단조 증가**(-0.04 → 0.92 → 1.23 → 1.57)시키고 **MDD를 단조 감소**
(-40% → -33% → -11% → -3%)시켰다. 즉 세 개선이 서로 다른 축에서 기여:

- **분기 펀더멘털**(C0→C1): 신호 자체를 강화(샤프 -0.04→0.92). 가장 큰 도약.
- **시장중립**(C1→C2): KR↔US 베타 제거로 MDD를 1/3로(−33%→−11%), 샤프도 개선.
- **레짐필터**(C2→C3): 고VIX 회피로 MDD를 −3%까지, 샤프 1.57. 절반의 시간만 베팅.

연구 서사가 성과로 수렴: *신호 없음(C0) → 신호 발견·강화 → 위험 제거 → 국면 회피.*

## 정직한 한계 (중요)

- **표본이 작다.** 총 리밸 ~19회, C3는 활성 ~9회. 샤프·MDD의 신뢰구간이 넓어
  **수치의 크기는 미확정**이다. 본 사다리는 "각 개선의 방향성"을 보이는 증거이지,
  실현 가능한 성과 보장이 아니다.
- **단일 강세장 구간**(2024~2026)만 포함 → 하락장 일반화 불가.
- 생존편향, 풀링 잔존(섹터 미중립), 거래비용 단순화(25bp 고정), 수정주가 미적용,
  레짐 임계값의 사후성. US 분기 재무 ~5분기 한계(분기화 실익은 주로 KR).
- **연구·학습용 기준선이며 실거래 전략이 아니다. 투자 자문 아님.**

## 재현

```bash
sp-poc        # 0단계 데이터 수집 검증
sp-baseline   # 1단계 가격 베이스라인
sp-horizon    # 타깃 기간 스윕(펀더멘털은 중장기 유효)
sp-longshort  # 롱숏(신호=알파 확인)
sp-stage3     # 분기 펀더멘털 + 거시 레짐
sp-regime     # 레짐 필터 전략
sp-neutral    # 시장중립화
sp-final      # 최종 ablation (이 문서)
```

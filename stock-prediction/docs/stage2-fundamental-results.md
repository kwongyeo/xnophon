# 단계2 펀더멘털 결과

가격/기술적 피처에 **point-in-time 펀더멘털 팩터**를 더했을 때 단계1 기준선을
이기는지, **동일 샘플·동일 워크포워드·동일 모델**로 공정 비교했다.

실행: `sp-stage2` (또는 `python -m stock_prediction.stage2`)

## 데이터 · 설정

| 항목 | 값 |
|---|---|
| 펀더멘털 소스 | DART `get_financial_account` (FY2023/24/25 사업보고서, 연결) |
| PIT 정렬 | 보고서 접수일(rcept_no)을 disclosed_at 로, merge_asof(backward) |
| 펀더멘털 피처 | f_roe, f_op_margin, f_liab_to_equity, f_rev_growth, f_book_to_price, f_earnings_yield |
| 가치 팩터 | BPS·EPS(주당) ÷ 주가 (주식수: yfinance) |
| 공통 샘플 | 6,230행 · 거래일 310일 · 종목 21 |

> 종목이 24→21로 준 이유: 금융지주 3곳(KB·신한·하나)은 CFS에 '매출액/영업이익'
> 계정이 없어(영업수익·이자수익 구조) op_margin 결측 → 공통 샘플에서 제외.
> 거래일이 460→310으로 준 이유: 첫 재무 스냅샷(FY2023)은 직전년이 없어
> f_rev_growth 가 결측 → 해당 구간(≈2024-06~2025-03) 제외. **남은 표본은 사실상
> 2025-03 이후**라는 점에 유의(아래 한계 참조).

## 해석 (정직한 평가)

- **펀더멘털이 기준선을 일관되게 이기지 못한다.** Ridge는 샤프 1.85→3.34로 크게
  개선됐지만 **RankIC는 여전히 ≈0(-0.001)** — 순위 예측력이 생겼다기보다 소수 종목
  집중 + 짧은 표본의 운에 가깝다. LightGBM은 오히려 **RankIC가 악화**(-0.056→-0.093),
  샤프만 소폭 상승.
- IC/RankIC가 모델 전반에서 0 부근 또는 음수 — **유의미한 횡단면 예측 신호는 확인되지
  않음.** 일부 수익/샤프 개선은 통계적으로 신뢰하기 어렵다.
- 결론: 이 데이터 규모에서 **펀더멘털 추가의 효과는 결정적이지 않다(inconclusive).**
  프레임(공정 비교·PIT 결합)은 정상 작동하나, 신호를 끌어내려면 더 넓은 유니버스와
  긴 표본이 필요하다.

## 한계 (결과 과신 금지)

- **표본이 매우 작다**: 21종목 · 310거래일 · 워크포워드 8폴드. 통계적 검정력 낮음.
- **사실상 단일 구간(2025-03~2026-06)**: f_rev_growth 결측으로 초기 구간이 잘림.
  → FY2022 보고서를 추가 수집하면 표본을 약 1년 늘릴 수 있다(후속 개선안).
- **연 1회 갱신**: 펀더멘털이 거의 정적 → 5일 단기 타깃과 시간 해상도 불일치.
  분기보고서(11013/11012/11014) 도입 시 갱신 빈도 4배.
- 대형주만 — 펀더멘털 팩터(특히 가치)는 중소형주에서 더 강한 경향. 생존편향 존재.
- 금융지주 매출/영업이익 계정 부재로 일부 종목 제외(섹터 편향).

## 후속 개선안 (효과를 키우려면)

1. **유니버스 확대**: KOSPI200/KOSDAQ150 전체 — 횡단면 종목 수 ↑.
2. **표본 기간 확대**: FY2020~ 재무 + 더 긴 가격 이력.
3. **분기 펀더멘털**: 갱신 빈도 ↑, point-in-time 해상도 ↑.
4. **타깃 기간 확대**: 5일 → 20·60일 (펀더멘털은 중장기에 더 유효).
5. **섹터 중립화**: 섹터 내 상대 팩터로 변환(금융/제조 혼재 편향 제거).

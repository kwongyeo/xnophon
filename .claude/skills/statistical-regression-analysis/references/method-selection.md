# 회귀분석 방법 선택 가이드 (recommendation logic)

이 문서는 데이터 특성 → 적절한 회귀방법을 고르는 결정 규칙이다.
`profile_and_recommend.py`가 이 로직을 코드로 구현하며, 아래는 그 근거·해설이다.

## 1단계 — 종속변수(Y) 유형으로 '모형군'을 정한다 (가장 중요)

| Y 유형 | 판정 기준 | 기본 모형 | 패키지/클래스 |
|---|---|---|---|
| **연속형** | 실수, 범위 넓음 | OLS 선형회귀 | statsmodels `OLS` |
| **이분형(0/1)** | 고유값 2개 | 로지스틱/프로빗 | statsmodels `Logit`/`Probit` |
| **카운트** | 음이 아닌 정수, 과분산 가능 | 포아송→음이항 | statsmodels `Poisson`/`NegativeBinomial` |
| **명목 다범주** | 순서 없는 3+ 범주 | 다항로짓 | statsmodels `MNLogit` |
| **순서형** | 순서 있는 3+ 범주 | 순서형 로짓/프로빗 | statsmodels `OrderedModel` |
| **비율/분율** | 0~1 사이 연속 | 분수 로짓(GLM) | statsmodels `GLM`(Binomial) |

> 과분산 판정: 카운트 Y에서 분산 ≫ 평균(분산/평균 > ~2)이면 포아송 대신 **음이항**.

## 2단계 — 데이터 '구조'로 모형군을 조정한다

| 구조 | 판정 기준 | 모형 | 패키지/클래스 |
|---|---|---|---|
| **횡단면** | 한 시점, 독립 관측 | 1단계 모형 그대로 | statsmodels |
| **패널(종단)** | 개체ID×시간 2중 식별자, 각 개체 다수 시점 | 고정효과/확률효과 | linearmodels `PanelOLS`(entity_effects), `RandomEffects` |
| **동적 패널** | 패널 + Y의 시차가 설명변수 | 차분/시스템 GMM | pydynpd |
| **공간 횡단면** | 지역 단위 + 공간 인접성·자기상관 | 공간시차/공간오차 | spreg `ML_Lag`/`ML_Error`, `GM_Lag` |
| **공간 패널** | 지역×시간 + 공간 의존 | 공간패널 FE/RE | spreg `Panel_FE_Lag`/`Panel_FE_Error` |
| **시계열** | 단일 개체, 다수 시점, 자기상관 | ARIMA/VAR | statsmodels `tsa` |
| **위계/중첩** | 그룹 내 상관(학생<학교 등) | 혼합효과 | statsmodels `MixedLM` |

> 패널 구조 자동 탐지: 두 열이 (ID, 시간)처럼 보이고 ID당 관측이 2+ 이면 패널 후보.
> 공간 구조: 지오메트리(shapefile/GeoPackage)나 좌표열이 있으면 공간모형 후보.

## 3단계 — '데이터 문제'로 추정법을 보정한다

| 문제 | 진단 | 대응 | 구현 |
|---|---|---|---|
| **다중공선성** | VIF > 10 | 정규화 회귀 | sklearn `Ridge`/`Lasso`/`ElasticNet` |
| **이분산** | Breusch-Pagan p<0.05 | 로버스트 표준오차(HC3) | statsmodels `.fit(cov_type='HC3')` |
| **내생성** | 설명변수-오차 상관(도구변수 존재) | 2SLS | linearmodels `IV2SLS` |
| **이상치/두꺼운 꼬리** | 잔차 진단 | 로버스트 회귀 | statsmodels `RLM`(Huber) |
| **비선형·분위 효과** | 평균 외 분위 관심 | 분위회귀 | statsmodels `QuantReg` |
| **고차원/예측중심** | 변수 ≫ 관측, 예측 목적 | 정규화/ML | sklearn |

## 추천 알고리즘 (요약)

```
1. Y 유형 판정 → 모형군 결정
2. 구조 판정(패널/공간/시계열/위계) → 모형군 조정
3. 진단(VIF·이분산·표본크기) → 추정 옵션/대안 추가
4. 1~3을 결합해 '주 추천 1 + 대안 2'를 제시, 근거와 함께 출력
```

## 표본 크기 주의

- n < 30: 회귀 자체가 불안정. 결과를 탐색적으로만.
- 변수당 관측 < 10: 과적합 위험 → 변수 축소/정규화 권장.
- 패널: 시간 T가 2뿐이면 사실상 1차 차분. 동적/공간패널은 T≥3 권장.

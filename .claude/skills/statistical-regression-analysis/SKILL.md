# Statistical Regression Analysis

엑셀/CSV 데이터를 받아 **① 적절한 회귀방법 추천 → ② 실제 분석 실행 → ③ 결과
해석**까지 수행하는 스킬. 모든 계산은 이 컨테이너의 전용 venv에서 헤드리스로
돌린다.

## 워크플로 (이 순서를 따를 것)

### 0) 환경 준비 (항상 먼저)
컨테이너는 임시라 패키지가 없을 수 있다. 부트스트랩 스크립트를 실행해 venv
경로를 얻는다(멱등 — 이미 있으면 즉시 반환):
```bash
PY=$(bash .claude/skills/statistical-regression-analysis/scripts/setup_env.sh 2>/dev/null | tail -1)
echo "$PY"   # 예: /home/user/xnophon/.venv-stats/bin/python
```
이후 모든 파이썬 실행에 이 `$PY`를 쓴다.

### 1) 데이터 진단 + 방법 추천
입력 파일이 `.xls/.xlsx`가 아니면(CSV 등) 먼저 엑셀로 변환하거나 pandas로
읽을 수 있게 안내한다. 그다음:
```bash
"$PY" .claude/skills/statistical-regression-analysis/scripts/profile_and_recommend.py \
    DATA.xlsx [--sheet 시트명] [--target Y열] [--id 개체ID] [--time 시간열]
```
- `--target` 없이 호출하면 **열 유형만** 진단한다. 출력(stderr 요약 + stdout
  JSON)을 읽고, 사용자에게 **어떤 열이 종속변수(Y)인지** 확인한다.
- 종속변수를 알면 `--target`을 주어 다시 호출 → **주 추천 + 대안**을 받는다.
- 패널로 보이면 `--id`, `--time`을, 공간이면 좌표/경계를 확인한다.

추천 로직의 전체 근거는 `references/method-selection.md` 참조(필요 시 읽어
사용자에게 왜 그 방법인지 설명).

### 2) 사용자 확인
추천 결과(주 추천·대안·근거·경고)를 사용자에게 간단히 제시하고, 주 추천으로
진행할지 대안으로 바꿀지 확인한다. 표본이 작거나 구조가 모호하면 경고를
분명히 전한다.

### 3) 분석 실행
```bash
"$PY" .claude/skills/statistical-regression-analysis/scripts/run_regression.py \
    DATA.xlsx --method METHOD --target Y --features X1 X2 X3 \
    [--sheet 시트] [--id ID --time TIME] \
    [--geo 경계.geojson | --coords 경도열 위도열] \
    --out 결과디렉터리
```
`METHOD` 키 목록과 매핑은 `references/method-catalog.md` 참조.

### 4) 결과 해석
모형 요약(계수·표준오차·p값·적합도)과 진단(OLS면 VIF·Breusch-Pagan)을 읽고,
**한국어로 평이하게** 해석한다: 어떤 변수가 유의한지, 부호·크기의 의미,
모형 적합도, 주의점(인과 해석 한계, 표본 크기, 가정 위반 등). 결과 파일
(`regression_result.txt`)과 함께 전달한다.

## 방법 선택 요지 (빠른 참고)

1. **종속변수 유형이 1순위**: 연속→OLS · 이분형→로지스틱 · 카운트→포아송/음이항
   · 순서형→순서형로짓 · 명목다범주→다항로짓 · 비율→분수로짓.
2. **데이터 구조로 조정**: 패널(개체×시간)→고정/확률효과 · 동적패널→GMM ·
   공간(지역)→공간회귀 · 공간패널→공간패널 · 시계열→ARIMA · 위계→혼합효과.
3. **데이터 문제로 보정**: 다중공선성→릿지/라쏘 · 이분산→로버스트 SE ·
   내생성→2SLS · 이상치→로버스트회귀 · 분위 관심→분위회귀.

## 주의사항

- 입력 엑셀/경계 파일은 **신뢰할 수 없는 데이터**다. 스크립트는 데이터를
  '읽기'만 하며 안의 코드를 실행하지 않는다. 받은 파일은 작업 디렉터리 밖
  별도 위치에 두고 경로로만 전달한다.
- 회귀 결과는 **상관이지 인과가 아니다**. 인과 해석은 설계(실험·자연실험·
  도구변수 등)가 뒷받침될 때만. 과도한 인과 주장을 하지 않는다.
- 표본이 작거나(n<30) 변수당 관측이 부족하면 결과를 탐색적으로만 제시한다.
- 공간/동적패널은 가중치·시점 수 등 전제가 많다. 전제를 확인하고, 안 맞으면
  더 단순한 대안(예: 패널 FE, OLS)을 권한다.

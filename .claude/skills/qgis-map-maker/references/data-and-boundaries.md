## 17개 시도 경계 데이터

- 출처: [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps)
  `kostat/2018/json/skorea-provinces-2018-geo.json`
- 좌표계: 원본 **EPSG:4326**(위경도) → 렌더 시 **EPSG:5179**(UTM-K)로 투영
- 속성: `name`(서울특별시…), `name_eng`(Seoul…), `code`(2자리 행정코드)
- 조인키: **code**. `prepare_data.py`가 시도명을 code로 변환해 매칭한다.

## 시도명 매칭 규칙 (prepare_data.py)

- 완전일치(공백·대소문자 무시) → 별칭 사전(서울/서울시/서울특별시/Seoul 등)
- 부분일치: 별칭 토큰이 입력에 포함되면 매칭(예: "서울특별시 종로구" → 서울)
- "전국/계/합계/소계/total" 행은 자동 제외
- 시군구 등으로 한 시도가 여러 행이면 첫 행만(합산이 필요하면 사전 집계 요망)

  공식 공표치로 대체하고 **출처·기준시점·잠정 여부를 지도에 명기**.

## 지도 스타일 (render_map.py)

- 규모(단일 값): 순차색 파랑 5단계, 분위(quantile) 구간
- 증감(값 2개): 발산색 적–백–청, 0 기준 대칭 구간, 라벨에 % 표기
- 구성: 제목·부제·범례(자동)·축척(km)·시도 라벨(흰 버퍼)·출처
- 해상도: 200 dpi, A4 가로 레이아웃

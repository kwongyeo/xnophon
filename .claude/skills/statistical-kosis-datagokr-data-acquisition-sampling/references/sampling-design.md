# 표본설계 레퍼런스

`scripts/acquire.py sample` / `estimate`의 근거와 설계 선택 기준.

## 목차
1. 표본추출이 필요한 경우와 필요 없는 경우
2. 설계 선택
3. 표본 크기
4. 가중치와 추정량 (스크립트 구현과 동일)
5. 검증 결과
6. 보고 시 함께 적을 항목

## 1. 언제 표본을 뽑나

- **KOSIS 집계표는 이미 전수·공표 통계다.** 집계표에서 다시 표본을 뽑아 추정하는 일은
  거의 없다. 사용자가 "샘플"이라고 하면 보통 다음 중 하나다:
  (a) 미리보기용 소량 조회(최근 1시점, 일부 분류) → 표본추출이 아니라 **시범조회**,
  (b) 분석용 하위집합(시도 몇 곳, 몇 년) → **필터링**.
  둘 다 확률표본이 아니므로 가중치를 붙이지 않고, "표본"이라 부르지 않는다.
- **data.go.kr의 개별 레코드(사업장·공고·기업·연설문)는 모집단 틀**이 된다. 전수 상세조회
  비용이 크거나(호출 한도, 상세 API 건별 호출), 수작업 코딩·검증이 필요할 때 확률표본을 뽑는다.
- KOSIS 집계값은 **층별 모집단 크기(N_h)나 보조정보**로 쓰인다. 예: 시도별 사업체 수로
  층 크기를 확인하거나, 표본 추정치를 공표 총계와 비교 검증.

## 2. 설계 선택

| 상황 | 설계 | 명령 |
|---|---|---|
| 틀이 균질, 단순 추정 | 단순무작위(SRS) | `--method srs` |
| 틀이 정렬돼 있고 고르게 퍼뜨리고 싶음 | 계통추출 (+ `--sort-by`로 암묵적 층화) | `--method systematic` |
| 하위집단(시도·업종)별 추정이 필요하거나 집단 간 차이가 큼 | 층화추출 | `--method stratified --strata …` |
| 층별 정밀도를 비슷하게 | 균등배분 | `--allocation equal` |
| 전체 총계 정밀도 최대화, 층별 분산을 보조변수로 앎 | 네이만 배분 | `--allocation neyman --value <보조변수>` |
| 소수 대형 단위가 총계를 좌우(꼬리 긴 분포) | 층화 + 전수층 | `--value <규모변수> --take-all-above <임계값>` |
| 단위가 자연 군집으로 묶이고 군집 단위 조회가 싸다 | 1단 군집추출 | `--method cluster --cluster …` |

- 층은 서로 겹치지 않고 모집단을 모두 덮어야 한다. 층 컬럼의 빈 값도 하나의 층으로 잡히므로
  미리 정리한다.
- 네이만 배분은 층별 표준편차를 모집단 틀의 `--value` 컬럼에서 계산한다. 이 컬럼은 **조사 전에
  알려진 보조변수**(전년도 값, 규모 지표)여야 한다. 추정 대상 변수 자체를 쓰면 순환이고, 그 값이 틀에
  이미 있다면 표본 추정 대신 전수 합계를 쓰면 된다. 보조변수와 관심변수의 상관이 낮으면 비례배분이
  더 안전하다.
- 전수층(`--take-all-above`)은 규모변수가 임계값 이상인 단위를 모두 포함한다(가중치 1, 분산 기여 0).
  나머지 표본 n − (전수층 크기)를 일반 층에 배분한다. 임계값은 규모변수 분포의 상위 1~2% 근처에서
  시작해, 전수층이 표본의 20~30%를 넘지 않게 정한다.
- 재현성: `--id-col`로 고유 ID 정렬 후 추출하면 입력 행 순서와 무관하게 같은 표본이 나온다.
  design.json에 시드·입력 SHA-256·ID 컬럼이 기록된다.
- 계통추출은 틀에 주기성이 있으면(예: 월별 반복 정렬) 편향될 수 있다. 의심되면 SRS로.
- 군집추출은 군집이 적으면 분산이 크다(검증에서 SRS 대비 표준오차 약 2.6배). 정밀도보다
  조회 비용 절감이 목적일 때만 쓴다.

## 3. 표본 크기

비율 추정 기준 근사 (95% 신뢰, 허용오차 e, 모집단 N):

n0 = 1.96² · p(1−p) / e²  (모르면 p = 0.5) → n = n0 / (1 + n0/N)

| e | n0 | N=5,000 | N=50,000 |
|---|---|---|---|
| ±5%p | 385 | 357 | 382 |
| ±3%p | 1,068 | 880 | 1,045 |
| ±2%p | 2,401 | 1,623 | 2,291 |

층별 추정이 필요하면 층마다 이 크기가 필요하다는 점(→ 균등배분)을 사용자에게 알린다.
API 호출 한도로 n이 제한되면, 그 n에서 기대되는 허용오차를 역산해 같이 보고한다.

## 4. 가중치와 추정량

설계가중치 `_weight` = 추출확률의 역수.

| 설계 | 가중치 | 총계 추정 | 분산 추정 |
|---|---|---|---|
| SRS / 계통 | N/n | N·ȳ | N²(1−n/N)s²/n (계통은 SRS 근사) |
| 층화 | N_h/n_h | Σ N_h ȳ_h | Σ N_h²(1−n_h/N_h)s_h²/n_h |
| 1단 군집 | M/m | (M/m) Σ t_i | M²(1−m/M)s_t²/m, 구간은 t(m−1) |

`(1 − n/N)`은 유한모집단수정(fpc). n_h = 1인 층은 층내 분산을 추정할 수 없으므로
(`s_h² = 0`으로 처리됨) 층당 최소 2개(`--min-per-stratum 2`)를 권장한다.

평균은 총계/N. 결측(수치 변환 실패) 행은 추정에서 빠지며 `n_missing`으로 보고된다.
무응답·결측이 많으면 가중치 조정(층내 응답률 보정)이 필요하다는 점을 한계로 적는다.

## 5. 검증 결과 (합성 모집단 N=5,419, 17개 층, 300회 반복)

| 설계 | 편향 | 경험적 SE | 95% CI 포함률 |
|---|---|---|---|
| SRS n=400 | −0.11% | 11,141 | 94.3% |
| 층화·비례 n=400 | −0.00% | 10,650 | 94.3% |
| 층화·네이만 n=400 | +0.38% | 10,345 | 95.3% |
| 군집 m=6/17 (t 임계값) | −0.86% | 28,684 | 93.3% |

추정량은 불편이고 구간 포함률이 명목 수준에 가깝다. 군집 수가 매우 적으면 포함률이
명목보다 낮을 수 있음을 보고서에 적는다.

꼬리가 긴 분포(사업장 N=7,416, 가입자수 최대 859, 17개 층, n=300, 300회 반복):

| 설계 | 편향 | 경험적 SE | 95% CI 포함률 |
|---|---|---|---|
| 층화·비례 | −0.26% | 17,773 | 89.0% |
| 층화·비례 + 전수층(≥200, 61개) | +0.55% | 13,380 | 91.3% |

전수층이 표준오차를 약 25% 줄인다. 다만 층당 표본이 작고 분포가 치우치면 정규근사 구간은
명목 95%보다 좁다. 이 경우 표본을 늘리거나 전수층 임계값을 낮추고, 남는 과소포함 가능성을
한계로 보고한다.

## 6. 보고 시 함께 적을 항목

- 모집단 틀: 출처, 수집일, 전체 건수 N, 완전성(manifest `complete`)
- 설계: 방법, 층/군집 변수, 배분 방식, n(층별 n_h), 시드
- 추정치: 값 ± 표준오차, 95% 신뢰구간, 결측 수
- 한계: 틀 누락(예: 미가입 사업장), 계통추출 주기성, 무응답

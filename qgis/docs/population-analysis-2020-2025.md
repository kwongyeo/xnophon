# 17개 시도 인구 변화 분석 (2020 → 2025)

QGIS 헤드리스 환경에서 17개 광역시·도의 주민등록인구 2020년 대비 2025년
증감을 단계구분도(choropleth)로 분석한다.

## 산출물

| 파일 | 내용 |
|---|---|
| `outputs/maps/population_change_2020_2025.png` | **증감률(%) 분석지도** (발산형: 청색=증가, 적색=감소) |
| `outputs/maps/population_2025.png` | 2025 인구 규모 분석지도 |
| `data/processed/sido_population.gpkg` | 경계+인구 병합·증감 계산 레이어 (EPSG:5179) |
| `data/processed/population_sido.csv` | 인구 원자료(편집 가능한 입력) |

## 재현 방법

```bash
source qgis/scripts/qgis-env.sh
python3.12 qgis/scripts/pyqgis/make_population_map.py
```

경계 GeoJSON이 없으면 스크립트가 GitHub(southkorea-maps)에서 자동 다운로드한다.

## 데이터 출처 ⚠️ 중요

| 연도 | 출처 | 신뢰도 |
|---|---|---|
| **2020** | 행정안전부 주민등록인구(12/31 기준) **확정 공표치** | ✅ 확정 (합계 51,829,023명 일치 검증) |
| **2025** | **잠정 추정치** | ⚠️ 검증 필요 |

> **KOSIS 직접 접근 불가:** 작업 환경(컨테이너)의 egress 정책상 `kosis.kr`,
> 행안부, e-나라지표 등 한국 통계 사이트가 모두 차단(403)되어 KOSIS에서
> 직접 내려받지 못했다. 2025 수치는 웹검색으로 확인한 **공식 앵커**
> (전국 51,117,378명·6년 연속 감소, 부산 약 324만, 서울 −32,280·경기 +35,450)에
> 정합하도록 구성한 **잠정 추정치**다(전국 합계 오차 약 0.05%).

### 정확한 수치로 교체하는 법

KOSIS 또는 행안부에서 아래 통계표를 내려받아 `population_sido.csv`의
`pop_2025` 열만 갱신한 뒤 스크립트를 다시 실행하면 된다.

- KOSIS 통계표: **DT_1B040A3** 「행정구역(시군구)별, 성별 인구수」
  (또는 DT_1YL20651E 「주민등록인구(시도/시/군/구)」)
- 행안부 주민등록 인구통계: https://jumin.mois.go.kr

경계: `southkorea/southkorea-maps`(kostat 2018) · 좌표계 **EPSG:5179**(UTM-K)

## 분석 결과 (잠정)

전국 주민등록인구는 2020년 5,182.9만 → 2025년 약 5,109.2만으로 **약 −1.4%
감소**(6년 연속 감소). 그러나 지역별로 뚜렷한 양극화가 나타난다.

**증가 (수도권·세종 집중)**
| 시도 | 증감률 |
|---|---|
| 세종특별자치시 | **+11.3%** |
| 인천광역시 | +3.0% |
| 경기도 | +1.9% |
| 충청남도 | +0.8% |

**감소 (지방 광역시·도)**
| 시도 | 증감률 |
|---|---|
| 경상북도 | −4.5% |
| 부산광역시 | −4.5% |
| 울산광역시 | −4.2% |
| 전라북도 | −4.2% |
| 전라남도 | −4.1% |
| 서울특별시 | −3.8% |

핵심 패턴: **수도권(경기·인천) 및 세종으로의 인구 집중**과 **지방 광역시·도의
지속적 인구 감소**라는 양극화. 서울도 절대 인구는 감소(−3.8%)하나, 그 인구가
경기·인천으로 이동한 것으로 해석된다(수도권 전체는 소폭 증가).

## 방법론

1. 경계(EPSG:4326)를 **EPSG:5179**로 투영(면적·형상 왜곡 최소).
2. `code`(2자리 행정코드)로 인구 CSV와 1:1 조인.
3. `change = pop_2025 − pop_2020`, `pct = change / pop_2020 × 100` 계산.
4. 증감률을 5계급 발산형(적–백–청)으로 단계구분, 시도명·증감률 라벨링.
5. `QgsPrintLayout`으로 제목·범례·축척·출처를 갖춘 지도를 PNG(200dpi) 내보내기.

## 회계 범위 규칙 (본 프로젝트 합의)
- 분석 단위가 「지자체 재정」일 때: **일반회계 + 특별회계** 통합. 기금은 별도.
- 결산값 우선. 예산은 비교용으로만.
- 명목값을 기본 저장. 실질화는 분석 시점에 GDP 디플레이터 적용.
